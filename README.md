# 后端与全栈工程师的技术手记

记录 Go 后端开发、前端技术、工程实践、AI 工具与职业成长中的经验。

## 栏目

- [开发技术](./开发技术/)：Go 语言，以及后续的 TypeScript、Vue、React 等开发实践。
- [工程实践](./工程实践/)：架构、数据库、中间件、云原生与部署运维。
- [AI 与工具](./AI与工具/)：AI 辅助开发、开发工具与效率实践。
- [技术成长](./技术人文与软技能/)：职业选择、协作与个人思考。
- [Java 旧栈](./Java旧栈/)：Java 阶段的技术笔记与历史存档。

## 关于

文章主要来自真实项目实践、问题复盘与持续学习。技术内容请结合对应版本和使用场景判断。

## 博客站点

仓库根目录已经包含 GitHub Pages 静态入口。推送到 `main` 或 `Development` 分支后，工作流会自动发布站点：

`https://555tt.github.io/tech-garden/`

本地预览可以直接运行：

```bash
python3 -m http.server 4173
```

然后访问 `http://127.0.0.1:4173/`。
